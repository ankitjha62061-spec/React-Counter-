
# React Counter App

A simple counter application built using **React**.  
This project demonstrates how to use the `useState` hook to manage and update state inside a functional component.

---

## 📸 Preview

The app shows:

- A heading
- The current counter value
- Two buttons  
  - **Add Value** → increases the counter  
  - **Remove Value** → decreases the counter  
- The counter value is also shown in the footer text



## 🧠 How It Works

The counter value is stored in React state:

```js
let [counter, setCounter] = useState(5)
```

Button clicks update the state using `setCounter`, which re-renders the UI.
